# KCBS010 日付チェック

## 1.データ形式のチェック
- [x] 復帰コードに空白がセットされている
- [x] 西暦日付の年下2桁が90より小さい場合年上2桁に20がセットされる
- [x] 西暦日付の年下2桁が90より大きい場合年上2桁に19がセットされる

- [x] 西暦が日付でない場合は復帰コードに"E"がセットされる
- [x] 月が1~12以外の場合は復帰コードに"E"がセットされる
- [x] 1月、3月、5月、7月、8月、10月、12月は日が1~31以外の場合は復帰コードに"E"がセットされる
- [x] 4月、6月、9月、11月は日が1~30以外の場合は復帰コードに"E"がセットされる
- [x] 2月は日が1~29以外の場合は復帰コードに"E"がセットされる
- [x] 月が2の時、閏年ではないかつ、29日だった場合は復帰コードに"E"がセットされる

## 2.処理全体の確認
- [x] 実行開始時に「*** KCBS010 START ***」がコンソールに表示されている
- [x] 実行終了時に「*** KCBS010 END ***」がコンソールに表示されている
- [x] コンソールにレコードの件数が「ITF-CNT:」「OTF-CNT:」で正しく表示されている
- [x] レコードの件数が一致している
- [x] レコード作成される前に初期化がされている
