# KJBM020 受注データ形式チェック

## 1.データ形式のチェック
- [x] ITFからOTFへすべての項目が転記されている
- [x] エラー区分テーブルに空白がセットされている
- [x] データ区分が"1"または"9"の場合エラー区分(1)が空白である
- [x] データ区分が"1"または"9"以外の場合、エラー区分(1)に"1"がセットされる
- [x] 受注番号が0ではない数字の場合、エラー区分(2)が空白である
- [x] 受注番号が0または、数字ではない文字の場合、エラー区分(2)に"1"がセットされる
- [x] 受注日付が正確な場合、エラー区分(3)が空白でかつ、西暦日付8桁が転記される
- [x] サブプログラムを使用して日付が正確かどうかチェックする
- [x] 受注日付が正しくない場合は、エラー区分(3)に"1"がセットされる
- [x] エラー区分(4)はスペースである
- [x] 商品番号が0ではない数字の場合、エラー区分(5)が空白である
- [x] 商品番号が0または、数字ではない文字の場合、エラー区分(5)に"1"がセットされる
- [x] 数量が1~999の範囲内の数字の場合、エラー区分(6)が空白である
- [x] 数量が数字ではない文字または、1~999の範囲外の場合、エラー区分(6)に"1"がセットされる

## 2.処理全体の確認
- [x] 実行開始時に「*** KJBM010 START ***」がコンソールに表示されている
- [x] 実行終了時に「*** KJBM010 END ***」がコンソールに表示されている
- [x] コンソールにレコードの件数が「ITF-CNT:」「OTF-CNT:」で正しく表示されている
- [x] レコードの件数が一致している
- [x] レコード作成される前に初期化がされている
