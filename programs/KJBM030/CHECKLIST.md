# KJBM030 受注データ商品番号チェック

## 確認内容の概要

## 1.マッチング処理の確認（ITF=IMF）
- [x] IMFの商品名が正しくセットされていること
- [x] IMFの単価が正しくセットされている
- [x] エラー区分(6)が空白の場合、「数量 × 単価」が正しく計算されセットされている
- [x] エラー区分(6)が空白以外の場合、金額に「0」がセットされている
- [x] 受注番号、受注日、数量などの基本情報がITFからOTFへ正しく転記されている

## 2.マッチング処理の確認（不一致やエラー区分あり）
- [x] (ITF < IMF)の場合、エラー区分(5)に"2"がセットされ、OTFへ出力される
- [x] ITFだけが残った場合、IMF終了後に残ったITFレコードに対し、エラー区分(5)に"2"がセットされ、OTFへ出力される
- [x] 前工程でエラー区分(5)に値がセットされている場合、マッチング処理を行わずそのままの内容でOTFへ出力される
- [x] (ITF > IMF)の場合、IMFの商品番号がITFより小さい場合、次のIMFを読み込み、ITFはそのまま保持される

## 3.処理全体の確認
- [x] 実行開始時に「*** KJBM030 START ***」がコンソールに表示されている
- [x] 実行終了時に「*** KJBM030 END ***」がコンソールに表示されている
- [x] コンソールにレコードの件数が「ITF-CNT:」「IMF-CNT:」「OTF-CNT:」で正しく表示されている
- [x] レコードの件数がITF、OTFの件数と一致している
- [x] レコードの件数がIMFのファイルの件数と一致している
- [x] レコード作成される前に初期化がされている
